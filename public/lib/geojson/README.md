# kml-geojson / shp-geojson
KML/KMZ、SHP 与 GeoJSON 格式互转工具库

## 简要介绍
`kml-geojson`（全局对象 `kgUtil`）提供 KML/KMZ 与 GeoJSON 格式互相转换；`shp-geojson` 提供 Shapefile 与 GeoJSON 格式互相转换。两者均为木遥开源的格式转换工具类，使用示例见上游仓库 README。
