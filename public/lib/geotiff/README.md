# geotiff.js + plotty
GeoTIFF 地理栅格解析与渲染库

## 简要介绍
geotiff.js 解析 GeoTIFF 地理栅格数据；plotty 提供栅格数据渲染（色带/图例），常配合使用。

## 相关地址

- github地址：https://github.com/santilland/plotty
