# Font Awesome
经典图标字体库

## 简要介绍
提供 CSS 与字体形式的矢量图标集；字体按 SIL OFL 1.1 分发，CSS 按 MIT 分发，文档按 CC BY 3.0 分发。

## 相关地址
- 官网地址：https://fontawesome.com
- github地址：https://github.com/FortAwesome/Font-Awesome

## 本地版本信息
4.7.0

## 本地文件说明
含 `css/` 与 `fonts/` 字体文件。
目录内文件：`LICENSE`、`OFL.txt`
