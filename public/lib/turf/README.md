# Turf
模块化地理空间分析 JavaScript 库

## 简要介绍
提供缓冲区、相交、裁剪、量测等地理空间分析函数（@turf/turf UMD 全量包，内嵌依赖自带 @license 注释）。

## 相关地址
- 官网地址：https://turfjs.org
- github地址：https://github.com/Turfjs/turf

## 本地版本信息
7.x（对应 @turf/turf 7.1.0）

## 本地文件说明
目录内文件：`LICENSE`、`turf.min.js`
