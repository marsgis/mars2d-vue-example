# Leaflet
开源的 JavaScript 交互式二维地图库

## 简要介绍
轻量、面向移动端的地图库，提供瓦片图层、矢量绘制、标注、交互控件等核心能力，插件生态丰富，是 Mars2D 的底层地图引擎。

## 相关地址
- 官网地址：https://leafletjs.com
- github地址：https://github.com/Leaflet/Leaflet
