# fonts
图标字体目录（Font Awesome、web-icons、Glyphicons Halflings）

## 简要介绍
汇集项目引用的图标字体资源：`font-awesome/` 为 Font Awesome 4.7.0，`web-icons/` 为 admui 配套的图标字体（两个子目录内各自另有 README 与许可证文件）；顶层 `glyphicons-halflings-regular.woff` 为 Bootstrap 3 样式引用的 Glyphicons Halflings 字体。

## 相关地址
- Font Awesome 官网：https://fontawesome.com
- Font Awesome github：https://github.com/FortAwesome/Font-Awesome
- Glyphicons 官网：https://www.glyphicons.com（Halflings 随 Bootstrap 3 分发：https://getbootstrap.com）

## 本地版本信息
Font Awesome 4.7.0；web-icons UI v1.1.0；Glyphicons Halflings（随 Bootstrap 3.x）

## 本地文件说明
子目录 `font-awesome/`、`web-icons/` 内的文件、许可与署名见各自 README.md；顶层 `glyphicons-halflings-regular.woff` 供 Bootstrap 3 默认样式按 `../fonts/` 路径引用。
目录内文件：`glyphicons-halflings-regular.woff`、`LICENSE`、`font-awesome/`、`web-icons/`
