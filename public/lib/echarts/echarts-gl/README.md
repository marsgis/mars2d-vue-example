# echarts-gl
ECharts 的 WebGL 三维扩展插件

## 简要介绍
为 ECharts 提供三维散点/曲面/地球等 GL 渲染能力。

## 相关地址
- github地址：https://github.com/ecomfe/echarts-gl

## 本地版本信息
2.0.8

## 本地文件说明
