# ECharts
Apache ECharts 商业级数据可视化图表库

## 简要介绍
基于 ZRender 的图表库，提供折线、柱状、散点、饼图、K 线、地图、关系图等丰富图表类型与交互；`echarts-gl/`、`echarts-liquidfill/` 子目录为官方插件（见子目录）。

## 相关地址
- 官网地址：https://echarts.apache.org
- github地址：https://github.com/apache/echarts
- GL插件地址：https://github.com/ecomfe/echarts-gl
- 水球插件地址：https://github.com/ecomfe/echarts-liquidfill

## 本地版本信息
echarts-6.1.0（取自 npm `echarts@6.1.0` 的官方 dist 构建，2026-11-03 替换 5.2.1 静态副本）

## 本地文件说明
同目录 `dark.js` 为 ECharts 官方主题（dark theme），随 ECharts 按 Apache-2.0 分发。
目录内文件：`dark.js`、`echarts.js`、`echarts.js.map`、`echarts.min.js`、`LICENSE`、`NOTICE-echarts`
